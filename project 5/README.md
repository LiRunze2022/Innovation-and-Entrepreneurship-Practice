# SM2算法软件实现与优化

## SM2 参数定义
SM2 使用特定的椭圆曲线参数（推荐曲线 `sm2p256v1`）：
- **素数域** ( $\mathbb{F}_p$ )，其中 ( $p$ ) 是一个大素数
- **椭圆曲线方程**：( $y^2 = x^3 + ax + b$ ( $\text{mod}\ p$ ) )
- **基点 ( G )**：曲线上的一个固定点
- **阶 ( n )**：基点 ( G ) 的阶( $n \times G = \mathcal{O}$ )

## SM2 密钥生成
### 私钥（d）
- 随机选取 $d \in [1, n-1]$## 2. SM2 密钥生成

### 公钥（P）
- 计算 $P = d \times G$（椭圆曲线点乘）
- 公钥 $P$ 是一个点 $(x_{P}, y_{P})$

## SM2 加密流程
**目标**：使用接收方的公钥 $P$ 加密消息 $M$

### 步骤
1. 生成临时密钥：
   - 随机选取 $k \in [1, n-1]$
   - 计算 $C_1 = k \times G$

2. 计算共享秘密：
   - 计算 $S = k \times P$
   - 分解 $S = (x_{S}, y_{S})$

3. 密钥派生（KDF）：
   - 输入： $x_{S} \Vert y_{S}$
   - 使用 KDF 生成密钥流 $t$

4. 加密消息：
   - 计算 $C_2 = M \oplus t$

5. 计算哈希校验：
   - 计算 $C_3 = \text{Hash}(x_{S} \Vert M \Vert y_{S})$

6. 输出密文：
   - 最终密文： $C = C_{1} \Vert C_{3} \Vert C_{2}$

## SM2 解密流程
**目标**：使用私钥 $d$ 解密密文 $C$

### 步骤
1. 解析密文：
   - 提取 $C_{1}$ 、 $C_{3}$ 、 $C_{2}$

2. 计算共享秘密：
   - 计算 $S = d \times C_{1}$
   - 分解 $S = (x_{S}, y_{S})$

3. 密钥派生（KDF）：
   - 生成密钥流 $t$

4. 解密消息：
   - 计算 $M = C_{2} \oplus t$

5. 验证哈希：
   - 检查 $\text{Hash}(x_{S} \Vert M \Vert y_{S}) \stackrel{?}{=} C_{3}$

6. 输出明文 $M$
